This project is for SIT305 Task 9.1

It is an android studio project which is an Lost and Found App

The app allows user to add , view and delete lost or found item records Users can select a Title, Category, Location and Date/Time for the lost or found item These will then be presented to the user in chronological order. Users can tap onto the event to view the details or delete the record
Users are also able to press onto "Show On Map" to have a visual representation of items nearby to them that are either lost or found
